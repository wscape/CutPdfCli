# PDF & Directory Explorer CLI (`CutPdfCli`)

터미널에서 디렉토리를 탐색하고 PDF 파일의 전체 경로 및 **정제된 목차(TOC) 텍스트**를 확인한 후, **목차의 파일명과 페이지 번호를 기반으로 PDF를 자동 분할(Split)하여 저장**하고 원본 파일까지 정리하는 대화형 CLI 도구입니다.

## 주요 기능

1. **상위 폴더(`..`) 자동 인식**
   - 현재 디렉토리가 루트(`/`)가 아닌 경우, 최상단에 상위 폴더 `📁 ..` 항목이 표시되어 이전 폴더로 쉽게 이동할 수 있습니다.
2. **폴더 및 PDF 파일 목록 필터링**
   - 현재 디렉토리 내의 하위 폴더와 `.pdf` 파일만 깔끔하게 리스트로 출력합니다.
   - 숨김 파일/폴더(`.git`, `.DS_Store` 등) 및 `__pycache__` 등은 자동으로 제외됩니다.
3. **간편한 디렉토리 이동**
   - 폴더(또는 `..`)를 선택하면 해당 폴더로 즉시 이동하여 내용을 새로고침합니다.
4. **PDF 파일 선택 시 절대 경로 표시**
   - PDF 파일을 선택하면 전체 경로(절대 경로)가 화면에 표시되며, macOS 환경인 경우 클립보드로 자동 복사(`pbcopy`)됩니다.
5. **동일 파일명의 `.txt` 파일 자동 감지 및 우선 참조** 📄
   - 선택된 PDF 파일과 동일한 폴더에 파일명(확장자 제외)이 동일한 `.txt` 파일이 있는 경우 (예: `Overview.pdf` ↔ `Overview.txt`), PDF 내부를 스캔하는 대신 **해당 텍스트 파일의 내용을 바탕으로 파일명 및 페이지 번호 목록을 자동 생성**합니다.
   - macOS NFD / 표준 NFC 유니코드 파일명 정규화를 완벽 지원합니다.
   - 분리 작업이 성공하면 원본 PDF 파일과 함께 해당 `.txt` 파일도 생성된 폴더로 함께 이동 보관됩니다.
6. **목차(Table of Contents) 텍스트 정제 출력 규칙** 📑
   - **목차 제목 제거**: 맨 위 헤더("목차", "Table of Contents" 등)를 자동 제거합니다.
   - **월/일 2자리 패딩**: 파일명에 사용되는 월과 일의 숫자가 한 자리인 경우 앞에 `0`을 자동으로 추가합니다 (예: `11월 1일` → `11월 01일`, `11월 8일` → `11월 08일`).
   - **중간 줄 삭제**: 다음 페이지 번호가 나올 때까지의 중간 설명/줄들을 건너뜁니다.
   - **페이지 번호 출력**: 접두어(`p.`, `쪽` 등) 없이 순수 **숫자만** 남겨 출력합니다 (예: `3`, `8`, `16`).
   - **반복**: 다음 제목 줄 출력 → 페이지 번호 직전까지 줄 삭제 → 페이지 번호(숫자) 출력을 끝까지 반복합니다.
7. **목차 확인 및 편집 (단일 리스트 UI & 영문 인터페이스)** 📑
   - 파일 탐색기와 동일한 깔끔한 단일 리스트 UI에서 목차를 확인하고 즉시 편집할 수 있습니다:
     - `[ 0] 🚀 Start PDF Split`: 최상위에 위치하며, 선택 후 `Enter`를 누르면 분할 작업을 즉시 실행합니다.
     - `[ 1..N] 📄 파일명 / 📃 페이지 번호`:
       - `Enter` (수정): 해당 줄의 파일명 또는 페이지 번호를 직접 인라인 편집합니다.
       - **페이지 기준 자동 재정렬**: 페이지 번호를 수정하면 변경된 페이지 숫자에 맞춰 전체 목차가 오름차순으로 자동 재정렬됩니다.
       - `⌫` (삭제): 백스페이스 또는 Delete 키로 선택한 섹션(파일명과 페이지 번호 쌍)을 한 번에 삭제합니다.
     - `[ N+1] ➕ Add New Section`: 리스트 마지막 항목에서 새로운 섹션을 추가할 수 있습니다.
       - `Enter`를 누르면 파일명(`[New Title]`) 인라인 입력 상태로 전환됩니다.
       - 파일명을 입력하면 페이지 번호(`[New Page]`) 입력 상태로 이어집니다.
       - 페이지 번호를 입력하면 해당 페이지 번호를 기준으로 전체 순서가 자동 정렬되며 삽입됩니다.
     - `[- / +] Page Adj`: 모든 항목의 페이지 번호를 일괄적으로 1씩 감소(`-`) 또는 증가(`+`)시킵니다.
     - `[Number] Quick Jump`: 숫자를 입력하여 원하는 항목 번호로 즉시 이동합니다.
     - `[Esc] Back`: 파일 탐색 목록 화면으로 안전하게 돌아갑니다.
     - `[.] Quit`: 프로그램을 종료합니다.
8. **PDF 자동 분할 및 전용 폴더 저장** ✂️
   - **전용 폴더 자동 생성**: PDF가 위치한 폴더에 파일명(확장자 제외)과 동일한 이름의 폴더가 없다면 자동으로 생성합니다.
   - **텍스트 기반 분할**: 정제된 목차 텍스트의 각 **제목(파일명)**과 **페이지 번호(시작 페이지 ~ 다음 항목 시작 전 페이지)**를 참조하여 원본 PDF를 개별 파일로 분할 추출합니다.
   - **원본 파일 자동 이동**: 분리 작업이 성공하면, 선택한 원본 PDF 파일도 해당 폴더로 깔끔하게 함께 이동 보관됩니다.
   - **실시간 진행률 표시**: 분할 진행 상황(항목별 번호, 파일명, 페이지 범위, 완료 여부)을 실시간으로 표시합니다.
9. **두 가지 조작 모드 지원**
   - **대화형 TUI 모드 (기본 터미널)**: 방향키(`↑`, `↓`, `←`, `→`)로 커서를 이동하고 `Enter`로 선택하거나, 번호 키를 눌러 바로 선택할 수 있습니다.
   - **표준 CLI 모드 (Fallback)**: 파이프라인이나 특수 환경에서도 번호 입력 방식으로 문제없이 동작합니다.

## 실행 방법

가상환경에 설치된 `pypdf`를 자동으로 인식하며, 환경이 없는 경우에도 macOS 내장 `PDFKit`을 Fallback으로 사용하여 안정적으로 동작합니다.

```bash
# 기본 실행 (현재 디렉토리에서 시작)
python3 main.py

# 또는 직접 실행 (실행 권한 포함)
./main.py

# 특정 경로에서 시작하고 싶을 때
python3 main.py ~/Documents
```

## PyInstaller 단일 실행 파일 빌드 (`dist/CutPdfCli`)

단일 바이너리 실행 파일로 빌드하려면 아래 방법 중 하나를 사용합니다:

```bash
# 방법 1: 제공된 빌드 스크립트 실행 (추천)
./build.sh
```

```bash
# 방법 2: PyInstaller 명령어로 직접 빌드 (--name 옵션 지정)
pyinstaller --onefile --clean --name CutPdfCli main.py
```

```bash
# 방법 3: CutPdfCli.spec 파일로 빌드
pyinstaller CutPdfCli.spec
```

> **참고**: `pyinstaller main.py`처럼 `--name CutPdfCli` 옵션 없이 실행하면 스크립트 파일명을 따라 `dist/main`으로 생성됩니다. `dist/CutPdfCli`로 생성하려면 반드시 `--name CutPdfCli`를 지정하거나 `./build.sh`를 실행하세요.

## 조작법 안내

### 파일 탐색 화면
- `↑` / `↓` : 폴더 및 PDF 파일 목록 이동 (하이라이트)
- `Enter` : 폴더 진입 또는 PDF 파일 선택
- `숫자 키` (`1`, `2`, `3` ...) : 해당 번호 항목으로 바로 이동
- `.` 또는 `Ctrl + C` : 프로그램 종료 (Quit)

### 진행 확인 및 수정 화면 (TOC Editor)
- `↑` / `↓` : 리스트 항목 간 이동 (하이라이트)
- `Enter` :
  - `[ 0] Proceed` 선택 시: PDF 분할 작업 시작
  - `[ 1..N]` 선택 시: 파일명 또는 페이지 번호 인라인 수정 (페이지 번호 변경 시 자동 재정렬)
  - `➕ Add New Section` 선택 시: 파일명 ➔ 페이지 번호 2단계 입력으로 새 섹션 추가
- `⌫` (Backspace / Delete) : 선택한 섹션(파일명 및 페이지 번호 쌍) 일괄 삭제
- `숫자 키` (`0`, `1`, `2` ...) : 해당 번호 항목으로 바로 이동 (Quick Jump)
- `-` / `+` : 모든 페이지 번호 일괄 1씩 감소 / 증가 (Page Adj)
- `Esc` : 파일 탐색 목록 화면으로 복귀 (Back)
- `.` 또는 `Ctrl + C` : 프로그램 종료 (Quit)
